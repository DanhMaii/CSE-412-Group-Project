# CSE 412 Group Project

This is a **vanilla JS + HTML project** using **Vite**, **TailwindCSS**, and **D3.js**.  
It includes **Prettier** with **Tailwind class sorting** and **Husky + lint-staged** for automatic formatting on commit.

---

## Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18+ recommended)
- npm (comes with Node.js)
- Git

---

## Setup Instructions (Local Development)

### 1. Clone the repository

```bash
git clone https://github.com/DanhMaii/CSE-412-Group-Project.git
cd cse-412-group-project
```

### 2. Install dependencies

```bash
npm install
```

This automatically runs the `prepare` script (`husky install`) which sets up Git hooks for pre-commit formatting.

### 3. Start the development server

```bash
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`) in your browser.
